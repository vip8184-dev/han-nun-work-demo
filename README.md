# 한눈업무 — 공개 업무자동화 시연

소규모 판매업체에서 반복하는 CSV 주문서 검토를 돕는 **독립 시제품**입니다.

- 기능: 가상 주문 예시/CSV 열기 → 필수열 확인 → 주문번호 기준 중복 **추정 표시** → 검토용 CSV 저장
- 개인정보 처리: 입력 파일은 브라우저 내에서만 분석하며 서버 업로드·결제·고객계정 연동을 하지 않습니다.
- 이 페이지는 주문 대행, 자동 발주, 회계 확정 금액, ERP 연결을 제공하지 않습니다.
- 실제 고객 건은 원본을 받기 전 익명 샘플과 작업범위/검수/가격/개인정보 처리 조건을 협의합니다.
